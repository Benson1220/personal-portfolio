# Benson｜個人作品集

使用 HTML、CSS 與 JavaScript 建立的個人作品集網站，
用來整理個人背景、專案作品與學習紀錄，並持續累積網站開發經驗。

## 線上網站

[瀏覽個人作品集](https://benson1220.github.io/personal-portfolio/)

## 網站內容

- 個人介紹
- 學歷與經歷
- 技術能力
- 專案作品
- 學習紀錄
- 聯絡方式

## 使用技術

- HTML：建立網頁內容與結構
- CSS：設定外觀、Grid 排版與響應式樣式
- Git：管理版本紀錄
- GitHub：保存與展示原始碼
- GitHub Pages：發布靜態網站
- JavaScript：處理專案學習心得的展開與收起互動

## 資料夾結構

- index.html：網站首頁與各個內容區塊
- assets/css/style.css：網站樣式與響應式設定
- README.md：專案說明
- .gitignore：排除系統檔與本機備份檔
- assets/js/main.js：專案學習心得的互動程式

## 本機瀏覽方式

1. 下載或複製這個儲存庫。
2. 使用瀏覽器開啟 index.html。

目前不需要安裝套件或啟動後端服務。
