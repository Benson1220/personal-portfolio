# Benson｜個人作品集

使用 HTML、CSS 與 JavaScript 建立的個人作品集網站，
用來整理個人背景、專案作品與學習紀錄，並持續累積網站開發經驗。

## 線上網站

[瀏覽個人作品集](https://benson1220.github.io/personal-portfolio/)

## 網站內容

- 個人介紹
- 學歷與經歷
- 技術能力
- 專案作品
- 學習紀錄
- 聯絡方式
- 專案詳情頁：說明開發目的、已完成內容、問題與解法

## 使用技術

- HTML：建立網頁內容與結構
- CSS：設定外觀、Grid 排版與響應式樣式
- Git：管理版本紀錄
- GitHub：保存與展示原始碼
- GitHub Pages：發布靜態網站
- JavaScript：處理專案學習心得的展開與收起互動

## 資料夾結構

- index.html：網站首頁與各個內容區塊
- assets/css/style.css：網站樣式與響應式設定
- README.md：專案說明
- .gitignore：排除系統檔與本機備份檔
- assets/js/main.js：專案學習心得的互動程式
- assets/images/favicon.svg：網站分頁圖示
- projects/portfolio.html：個人作品集網站的專案詳情頁

## 本機瀏覽方式

1. 下載或複製這個儲存庫。
2. 使用瀏覽器開啟 index.html。

目前不需要安裝套件或啟動後端服務。
## 列印與另存 PDF

在瀏覽器開啟網站後，使用瀏覽器的列印功能：
Mac 按 Command 搭配 P；Windows 按 Ctrl 搭配 P。

網站會套用列印專用樣式，隱藏導覽列、頁尾與操作按鈕，
並將首頁改為單欄。可在列印視窗中選擇另存為 PDF。

列印前請先查看預覽，頁數會隨內容與紙張設定而變動。
