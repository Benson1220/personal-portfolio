PROJECT DETAILS

個人作品集網站

從 HTML 與 CSS 開始，逐步加入 JavaScript， 並透過 GitHub Pages 發布的個人網站。

專案目的

建立可以長期維護的個人作品集， 整理個人背景、技術學習與專案成果， 為未來求職逐步累積實作紀錄。

第一階段使用 HTML、CSS 與 JavaScript， 從基本網頁結構開始學習，再逐步改善排版與互動。

已完成內容

  • 建立個人介紹、學經歷、技能、作品與聯絡區塊。
  • 使用 CSS Grid 與媒體查詢調整桌面和窄螢幕排版。
  • 使用 JavaScript 實作學習心得的展開與收起。
  • 加入跳到主要內容連結與鍵盤焦點樣式。
  • 提供列印專用樣式。
  • 使用 Git 管理版本，並透過 GitHub Pages 發布。

問題與解法

拆分 CSS 後，頁面失去樣式

檢查樣式檔是否有內容並完成儲存， 同時確認 HTML 的連結路徑與實際資料夾位置一致。

修改連結後，顯示文字沒有跟著更新

理解 href 決定連結目的地， 標籤內的文字則決定畫面顯示內容，兩者需要分別修改。

本機修改沒有立即出現在線上網站

區分本機檔案與線上版本， 完成本機測試、提交及上傳後， 再等待 GitHub Pages 部署並檢查結果。
